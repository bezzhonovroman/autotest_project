# Программа голосования

Консольная программа на Python для проведения голосования. Пользователь выбирает вариант по номеру, после завершения выводятся итоги и победитель.

## Требования

- Python 3.8+

Дополнительные зависимости не нужны.

## Запуск

```bash
python main.py
```

## Как пользоваться

После запуска программа показывает варианты ответа:

1. Да
2. Нет
3. Может быть

Введите номер варианта, чтобы отдать голос. Чтобы закончить голосование, введите `стоп` или `stop`.

Пустой ввод и некорректные значения (не число, номер вне диапазона) отклоняются с подсказкой, голосование продолжается.

## Итоги

После завершения программа выводит:

- количество голосов по каждому варианту;
- общее число голосов;
- победителя или список вариантов при ничьей.

Если голосов не было, об этом сообщается отдельно.

## Тесты

Автотесты написаны на `pytest` и лежат в каталоге `tests/`. Фикстуры вынесены в `conftest.py`, настройки запуска — в `pytest.ini`.

### Установка зависимостей

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Запуск

```bash
pytest
```

Полезные варианты запуска:

```bash
pytest tests/test_voting.py::TestVote
```

```bash
pytest -k winners
```

### Фикстуры (`conftest.py`)

| Фикстура | Что готовит |
| --- | --- |
| `options` | Список вариантов ответа `["Да", "Нет", "Может быть"]`. |
| `voting` | Новый объект `Voting` без голосов. |
| `voted_voting` | Голосование с уже отданными голосами: «Да» — 2, «Нет» — 1. |

### Что проверяют тесты

| Группа | Проверки |
| --- | --- |
| `TestCreation` | Новое голосование стартует с нулевыми счётчиками для всех вариантов. |
| `TestVote` | Голос засчитывается нужному варианту (параметризация по номерам 1–3); номер вне диапазона (`0`, `-1`, `4`, `100`, параметризация) вызывает `ValueError` и не меняет счётчики; повторные голоса суммируются. |
| `TestWinners` | Без голосов `get_winners()` возвращает `None`; при явном лидере — один вариант; при равенстве — все лидеры. |

Всего 12 тестов (с учётом параметризации): покрыты как позитивные сценарии (учёт голосов, определение победителя), так и негативные (голос с номером вне диапазона).

## Класс `Voting`

Логика голосования собрана в классе `Voting` в файле `main.py`.

| Метод | Описание |
| --- | --- |
| `__init__(options)` | Создаёт голосование. Пустой список вариантов вызывает `ValueError`. |
| `show_options()` | Печатает пронумерованный список вариантов. |
| `vote(chosen_number)` | Засчитывает голос по номеру варианта (нумерация с 1). |
| `get_winners()` | Возвращает список лидеров или `None`, если голосов ещё нет. |
| `total_votes()` | Возвращает сумму всех голосов. |
| `show_results()` | Печатает итоги голосования. |
| `get_valid_choice()` | Читает ввод пользователя, пока не получит корректный номер или команду остановки. |

Варианты по умолчанию задаются в функции `main()`. Чтобы провести голосование с другими вариантами, передайте свой список в конструктор:

```python
voting = Voting(["Кот", "Пёс", "Попугай"])
```
